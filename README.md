# Profile Card  

A simple responsive profile card built with **HTML, CSS, and JavaScript**.  
It features an avatar, bio, hobbies/dislikes, social links, and a live clock.  

---

##  Features  
- Responsive layout (avatar on left for wide screens, stacked on mobile).  
- Live current time (with milliseconds).  
- Social links (Twitter, GitHub, LinkedIn).  
- Hobbies and dislikes displayed side by side.  

---

##  Project Structure  

project-folder/
├── index.html # Main HTML file
├── style.css # Stylesheet
├── script.js # JavaScript for dynamic time
└── images/
└── profile.png # Your profile avatar

## 🛠️ Running Locally  

1. **Clone the repository**

   git clone https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git

Navigate into the project folder

cd YOUR-REPO-NAME
Open in browser

Option A: Just double-click index.html (works fine).

Option B (recommended): Use a local server for a smoother dev experience.
If you have VS Code, install the Live Server extension → right click index.html → Open with Live Server.
